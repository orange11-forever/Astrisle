# 蓝色大肥鱼／鲸鱼娘：形象参考与署名

核对日期：2026-11-11。本文记录 Astrisle 本次 Q 版角色改编的来源、实际看图结果与使用边界；不代表 DeepSeek 官方设定。

## 本次采用的造型

本轮后续用户提供了[这张指定参考图](https://tiebapic.baidu.com/forum/pic/item/a88dfc3c269759ee8656b3c8f4fb43166d22df2d.jpg?tbpicau=2026-11-22-05_25b52752db5143aff93ade93a1d17587)，并否定了第一版程序化模型的外观。随后用户明确要求严格还原 `.superpowers/references/blue-whale-girl-yunyuesama-character-sheet.png`。**该设定表的正、侧、背视图为主要建模标准，用户提供的单图补充正面细节**：较低而宽的脸、约占身高一半的大头、略带慵懒的蓝色眼睛、成片刘海与薄布料褶边。只将单图作为用户提供的外观参考，不凭图片托管地址推断作者或首次发表时间；来源图仍仅保留在本地忽略目录。

用户选择 **Q 版、更加可爱、替换现有三个角色，并明确去掉尾巴**。参考图中的鲸尾属于来源形象，本次模型不保留尾巴。三位角色使用同一套鲸鱼娘视觉语言。

- 约 2.5 头身，较大的圆润头部、小巧身体与短四肢；这是本次风格化取舍，不是声称原作者规定了唯一比例。
- 深蓝／钴蓝发根向浅蓝发梢过渡的长发，分组弯曲的发束、中央刘海与一根弧形呆毛。
- 大蓝眼、柔和脸颊和小嘴。两侧头鳍为深蓝上表面、浅色下缘；保留鲸鱼特征，不改成猫耳。
- 白色褶边女仆发箍、蓝色侧蝴蝶结，深蓝长袖裙、白色围裙与褶边；围裙保留简化鲸鱼图案，少量金色饰边，白袜与深蓝玛丽珍鞋。
- 头发、头鳍、发箍、围裙构成主要轮廓。保留完整衣装，采用适合小尺寸 3D 画面的简化装饰。
- **无尾巴**。来源中常见的一条鲸尾和个别二创中的双尾都不进入本次模型。

上述取舍以作者女仆立绘的共同特征为基础，并参考社区 Q 版三视图；不是原作或任一社区图片的逐像素复刻。
