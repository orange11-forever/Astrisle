# 第十六阶段 · 观星台与夜空

把主岛现有的望远镜接到栈道上，让用户能从工作室抵达观星台，在栏杆和低灯旁自由抬头看星。保留现有工作区、伙伴活动和自由镜头。天气变化单独排期。

1. 从场景视角选择「观星台」，或点望远镜前往。短途镜头沿栈道进入平台，减少动效时直接到达。可以自由看向天空，随时回到工作室全景。
2. 默认以本机时间决定岛上天色，设置中可预览白昼、黄昏和夜晚。天色联动天空、岛上照明和平台灯光，人物特写继续使用原有布光。
3. 暮色里先看见亮星，夜深后显出暗星和银河的尘带。用不同亮度、疏密和色温给夜空增加层次。月色下的望远镜、人物和栈道仍要能辨认。
4. 分别验证光照变化、视角切换、手动环绕、减少动效、设置恢复和 2D 切换。使用隔离数据在 Electron 中回读实际画面，并按仓库约定运行 Windows 验证。

## 本地验收

通过 `pnpm.cmd demo` 加载本机配置的三个蓝发角色模型，在隔离的 Electron 工作区拍摄了[平台上仰望银河](../../development/screenshots/stage-16-observatory.png)和[夜间岛屿全景](../../development/screenshots/stage-16-night-island.png)。在桌面和窄屏中检查了望远镜与天空的取景，拖动后切换天色，镜头保持在用户选择的方向。

Edge 用例分别从视角菜单和望远镜进入，记录了正常动效下镜头沿栈道移动的多帧位置，并核对最终位置已越过平台入口。减少动效、自由环绕、回到全景、切换 2D 和重载后的天色偏好也经过验证。[视角回归](../../../tests/e2e/camera-navigation.spec.ts)

在带 8.3 短路径的 Windows 临时目录下完成全量验证。类型检查、格式检查和桌面构建通过，391 项单元与集成测试、17 项 Office 测试和 61 项 Edge／Electron 用例全部通过。
