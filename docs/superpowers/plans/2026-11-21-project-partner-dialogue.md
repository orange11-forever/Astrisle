# 第十四阶段 · 项目上下文伙伴对话

让用户从岛上或「伙伴与任务」选择一位伙伴，询问当前委托的进度、分工和复核原因。回答附带可打开的资料，分别定位任务、成果的确切版本和复核证据。[阶段方向](../../development/modern-features-backlog.md)

1. 共享接口与桌面桥接。`askPartner` 接收委托 ID、伙伴 ID、问题和最多四轮对话上下文。主进程验证请求并取得当前显示名称。运行时从委托快照确认伙伴身份。
2. 只读回答。用已配置的模型和有界的委托、任务、版本、复核摘要回答。记录只取自当前委托，按稳定 ID 关联。模型返回的引用必须能够在本次发给模型的资料中找到。提问不会执行项目工具或修改委托。
3. 场景与面板。3D 通过人物姓名入口进入对话，2D 通过「伙伴与任务」选择。按委托和伙伴区分会话，支持追问、失败重试、键盘提交和跳转资料。在本次打开工作室期间保留对话。
4. 验收。以隔离数据和本地模型服务实际询问生产者与复核人，从回答打开任务、指定版本和证据。检查跨伙伴、跨委托隔离，缺少模型时的提示，以及切换期间较晚返回的答复。
