## 下一阶段优先项：新增自定义工作伙伴

2026-11-19 确认：每位新建人物都可以接委托，也可以作为另一位伙伴的独立复核人。当前版本可配置 Mori、Luma 和用户化身的外观，新增独立伙伴待实施。

- 在“角色外观与名称”中提供“添加伙伴”，输入名字、导入模型并调整朝向。每个伙伴有独立、稳定的身份标识。改名后，历史任务、成果和复核记录仍能找到原来的角色。
- 新伙伴可以出现在岛上，有可达的起始位置，参与散步、休闲和工位活动。角色档案与模型选择在重启后恢复，旧版三角色存档可继续使用。
- 将规划器、调度器和任务面板接到实际伙伴名单。新伙伴可独立承担生产任务、与现有伙伴交接，也可以复核其他伙伴的成果。沿用同一成果由不同人物生产和复核的规则。
- 验收时实际创建第四位人物，重启后完成两份委托：先由新人生产、Mori 或 Luma 复核；再由现有伙伴生产、新人复核。核对岛上角色、工作面板、版本记录三处的身份一致，并验证系统拒绝自审。

正式展示使用当前用户模型，自动化测试使用隔离数据。第十一阶段的场景、交互和验证范围见[开发记录](stage-11.md)。
