# 第二阶段：任务续接与鲸鱼伙伴

本阶段从已合并的 `2b37aa9` 继续开发；基线为 51 项 JavaScript 测试。完整 v0.1 计划仍是后续目标，本记录只覆盖本阶段实际改动。

## 任务续接

- 工具请求与结果分别保留，避免完成回执覆盖工具名和参数；旧 SQLite 数据按事务迁移，可从已有工具证据恢复旧请求身份。
- 恢复时区分纯模型请求中断与工具副作用未知。重启后保持暂停，未知写入需要保存明确的核查结论，不能自动重放。
- 每次续接读取当前任务的历史动作和当前文件状态，保留用户回答、产物版本与复核证据；历史结果不冒充当前文件内容。
- 已固定的输入版本不再在续接时覆盖任务副本，用户暂停期间的修改得到保留。

故障测试使用真实 SQLite、文件和独立 Node 子进程；模型使用本机 HTTP 替身。替身测试不构成真实供应商能力验收。

| 中断位置 | 本阶段要求 |
|---|---|
| 模型请求中断 | 无工具副作用时允许从现有记录继续；不虚构未完成写入 |
| 工具已开始、尚未产生副作用 | 无可靠回执时仍保持待核查 |
| 文件已写入、回执未提交 | 保留实际文件，要求核查，不重放旧写入 |
| 回执和证据已提交 | 保留已完成动作，后续模型获得该动作结果 |
| 写入执行器抛出异常 | 无法证明未发生副作用时保持未知状态 |

## 角色更新

用户指定参考蓝色大肥鱼娘的近期人物形象，并确认 Q 版、更加可爱、替换所有现有人物、去掉尾巴。三位角色仍对应原有的 Mori、Luma 与用户化身，模型造型不决定实际模型供应商或任务能力。

视觉参考、作者及日期见 [来源说明](../concepts/blue-whale-girl-references.md)。来源图不随应用分发。模型保留蓝色长发、鲸鳍发饰、蓝白裙装等识别特征，按用户要求省去尾巴；场景沿用原有星岛布局。

用户否定了第一版球体、管状发束与珠状装饰的外观，并指定了正面单图和 YunYueSama 多视图设定表。第二版据此重做大头短身比例、低而宽的脸、浅层眼部、闭合发壳、宽发片和布料褶边，并使用较接近参考的平面色阶。头发覆盖与围裙分离均有可见性射线回归，不能仅凭顶点合法就当作外观已还原。

新增“角色特写”视角，可分别查看三位伙伴、拖动旋转和缩放，或回到全景。2D 模式与减少动效继续可用。动作只消费业务状态，不参与派单、权限或完成判定。

## 验证

2026-11-11 最终集成验证：

| 检查 | 实际结果 |
|---|---|
| `pnpm.cmd test` | 15 个文件、78 项通过，含 21 项续接和 6 项模型测试 |

| `pnpm.cmd test:ui` | 5 项通过，含真实 Electron、角色旋转、2D/3D 往返、窄屏布局 |
| `pnpm.cmd format:check` | 通过 |
| `node scripts/export-character.mjs` | GLB 导出及真实 GLTFLoader 回读通过；边界、三角面数和命名关节一致 |

总计 93 项自动化测试通过。一次并行检查期间的浏览器测试在移动端截图阶段耗尽 60 秒总时限；trace 中浏览器启动、建页和鼠标操作也整体变慢。停止并行验证后，原阈值下完整浏览器／Electron 套件 26.6 秒通过，没有延长超时或删除断言。

最终模型为 84 个网格、62,440 个三角面、19 个材质，高约 1.852 米，GLB 为 4,068,728 字节。为闭合发壳、分层头发及布料细节，将首轮 35,000 三角面目标调整为 65,000 上限；这是一项保真度与运行成本的取舍，不是性能基准结论。导出包含 unlit 材质扩展、没有外部贴图、没有尾巴几何。

预览：[正面](screenshots/whale-girl-closeup.png)、[斜侧面](screenshots/whale-girl-three-quarter.png)、[背面](screenshots/whale-girl-back.png)、[工作室](screenshots/whale-girl-studio.png)、[窄屏](screenshots/whale-girl-mobile.png)。这些是应用中实际渲染的程序化模型，不是图像生成工具制作的效果图。

独立运行时审查发现的 3 项重要问题均有先失败再通过的回归：未答审批被恢复操作绕过、历史证据造成上下文膨胀、整合异常掩盖部分写入。美术检查另外推动了围裙穿插、发根与侧面覆盖、后发分层修正。技术测试通过不代表用户已经认可外观或达到严格复刻；外观以用户查看指定设定表与实际模型后的反馈为准。

运行时改动已保存为本地提交 `9b451f1`。用户请求查看后，曾启动最新 Electron 构建，并确认窗口标题为「Astrisle · 星岛工作室」、进程正常响应。桌面控制工具因沙箱辅助进程故障无法切换镜头。随后按用户要求关闭窗口；收到卡顿反馈后，只读确认没有委托，完整停止了本轮演示进程树。布局和性能反馈转入下一项工作，不将本阶段自动化测试当作性能验收。

## 范围说明

本阶段不宣称完整 v0.1 验收。多进程租约、进程树隔离、可调整预算、原项目安全写回、真实模型试跑、Office 应用版式检查和正式发行仍未完成。角色为可编辑的程序化几何与分组关节，不是已完成蒙皮、表情绑定和全套美术动作的最终资产。
