# 第十一阶段 · 花港小镇与委托动态

2026-11-18，从第十阶段合并提交 `f8db52b` 继续开发。

## 在工作室中体验

- **看工作进展。** 打开一份委托的“目标与计划”。“委托动态”倒序展示最新四条真实运行事件，可逐批查看更早记录。展开一条记录可读原始消息，有任务关联时可以进入对应任务。运行中由桌面快照推送更新，重新进入委托会读取已保存的历史。
- **为岛屿选色。** 进入已有岛屿，在“工作室设置 → 岛屿主题”选择海风青、紫藤雾、杏色晴或蔷薇湾。配色保存在本机，各工作空间独立。选择“自动”恢复该岛原本的配色。切换配色保留原有地形和镜头。
- **使用场景工具。** 对照架、回信匣、交付港、港务处和码头柜台平时只显示模型。鼠标移上模型或用键盘聚焦会显示名称和状态，点击、回车或触屏点按进入对应面板。空闲时主场景底部只保留“新委托”。设置按场景、角色与模型连接分组，可直接跳转。
- **环岛观察。** 温室和主岛由短桥相连，玻璃后可看到种植架和幼苗。茶椅旁的备茶架摆有杯具、布巾和花枝。低角度可看到崖层、岩簇和矿晶，池边有沿岸的浅水和植被。远眺可见带望远镜的穹顶观测站、飞艇系泊台，绕到背面可见双拱水渠与落水。

## 实现范围

### 功能分区与连接

| 区域 | 场景中的用途 | 与相邻区域的连接 |
|---|---|---|
| 中央工作室 | 天球仪计划桌、双人工位和阅览廊分别打开目标、任务与检查面板。拼花木台上的桌脚、台灯和书脊使用统一的铜色收边。 | 木台接环形步道，沿环道可到两个桥头。 |
| 温室花园 | 花房内的育苗台与外侧茶席、长椅、秋千构成休闲区。可在视角选择器中进入“温室花园”。 | 从环道的路缘开口踏上石铺短径，再经石桥到温室。 |
| 花市与港务街 | 面包铺、旅店、花铺和港务所沿岸排列。港务所可打开当前委托的目标与计划。伙伴空闲时可过桥看花。 | 花港木桥连到主岛环道，街边灯串沿着可步行的码头铺装延伸。 |
| 交付码头 | 帆船和花船停靠在街前水道。交付台显示当前成果状态，选择它可进入成果与验收。 | 港务所与交付码头共享沿岸街道，可从“花港街景”一并观察。 |
| 外围浮岛与远景 | 观测站、系泊飞艇、水渠和落水构成环绕地标，远处的山脊、云层、信标与行星区分前后景。 | 作为背景观景区，伙伴的行走路线集中在主岛和花港。 |

委托动态使用现有 SQLite 事件及桌面订阅。旧记录保留原始消息和现有的任务关联，本轮新增写入的工具开始、工具回执、任务完成和中断事件补记任务与伙伴。较早返回的快照不能覆盖同一委托的较新事件序列。

木台、环道、桥面和港街分别建模。桥的中心线、桥头位置与甲板高度由建模和导航共用。角色沿通道过桥，接到工作后沿可行走路线返回。水面、房屋和远景不属于通道。静态道具按材质合并几何，水滴共享一个实例网格，减少动效模式显示静态落水。

### 后续扩建规划

- 温室可从门前石桥继续接入中央过道，增加育苗台前的照料活动。需要先定义门洞净空、停靠点和两位伙伴的占用规则。
- 港街可从收货柜台向仓库后场延伸，承接按成果版本查看差异、提交返工说明的流程。当前柜台已接通成果面板，版本差异与定向返工属于后续功能。
- 观测站可以承接跨委托的进度总览。开放登岛时需要补上通行设施和往返路线，当前它是眺望地标。
