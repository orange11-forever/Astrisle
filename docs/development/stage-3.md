## 本机模型与继续工作所需状态

用户指定的 `蓝发女仆3d模型.glb` 已通过真实 `CharacterStore` 导入三位角色，并保存到 `.astrisle-dev/character-assets/`；配置在 `.astrisle-dev/characters.json`。三位角色共用一个资产，名字仍为 Mori、Luma、我，用户可自行修改。

该文件为 18,128,720 字节、502,178 个三角面、一个网格／材质／内嵌 JPEG，没有骨骼或动画。文件原始正面朝 +X；本机三个角色均已保存为 270°，使正面朝向场景 +Z。只修改外层变换，原文件与模型副本的几何字节不变。静态模型目前仅整体移动和转向，不自动生成手脚动作。

用户模型、配置和预览均留在被 Git 忽略的本地数据目录，没有并入公共角色资产。**不要清理 `.astrisle-dev/`。** 本地预览位于 `.astrisle-dev/previews/cosmic-studio.png`、`imported-character.png` 和 `cosmic-mobile.png`。预览使用真实用户 GLB 和测试 HostAPI，不把测试工作空间当成真实业务运行记录。

后续人物继续以用户提供的模型为准；助手负责场景，不再把旧程序化角色当成本机当前角色。旧角色仅作为未导入时的回退项。

## 性能证据

在同一台机器的无界面 Edge 上采样，检测到 ANGLE / NVIDIA RTX 5060 Laptop GPU / D3D11。采样使用真实 WebGL 调用计数；这不是 Electron 的无插桩 CPU、GPU 占用或长期性能验收。

| 场景 | 每帧绘制调用 | 每帧提交三角面 |
|---|---:|---:|
| 优化前工作室，原默认角色 | 2,656 | 939,082 |
| 优化后工作室，相同默认角色 | 468 | 230,848 |
| 优化后工作室，用户提供的模型 | 219 | 1,550,062 |
| 用户模型特写 | 3 | 502,436 |
| 优化后减少动作、静止场景 | 0 | 0 |

旧版本即使减少动作仍持续绘制，且存在方向阴影和接触阴影的重复场景遍历。合并静态环境使其源代码推算调用量从 345 降到 6。新工作室没有重复阴影帧缓冲；绘制缓冲从原 DPR 1.6 降为 1，像素数约为原来的 39%。环境动画采样约 23–25 帧/秒，符合最多 30 次/秒的调度预算；该上限不限制普通界面交互。

用户模型的三角面数更高，所以不能把调用减少等同于所有 GPU 成本都按同一比例下降。三个角色的真实加载记录为一次字节加载、无加载错误。无界面标签切换没有产生真实失焦，因此没有伪造后台 GPU 测量；失焦和隐藏的调度行为由事件与计时器测试覆盖。

原始测量与复现脚本保存在 `.superpowers/performance/`（忽略目录），包括 `baseline.json`、`after-fallback.json`、`after-supplied-model.json`。复测会暂时启动本机服务器与无界面浏览器，结束后自动关闭。
